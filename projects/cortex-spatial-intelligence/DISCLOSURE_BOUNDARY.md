# Cortex Spatial Intelligence public disclosure boundary

## Eligible for this release

- Abstract system boundaries and observable contracts.
- Wholly synthetic map, merchandise, list, campaign, and interaction examples.
- Independently written standard reference algorithms used only for public review.
- Deterministic test inputs, expected behavior, hashes, and aggregate results.
- Bounded production test totals and a private commit digest, labeled as non-reproduced private evidence.
- Limitations, rejected inputs, failure cases, and reviewer questions.

## Excluded

- Source, history, build artifacts, or package contents from the private production repository.
- Proprietary routing, optimization, validation, policy, evidence, adapter, navigation, positioning, ingestion, or deployment implementation.
- Real customer, retailer, employee, visitor, patient, student, or user data.
- Real floor plans, photographs, map evidence, SKU catalogs, product locations, movement histories, or operational data.
- Credentials, tokens, keys, secret locations, private URLs, internal service names, endpoints, network layouts, deployment instructions, or machine identifiers.
- Private commercial terms, customer negotiations, unreleased patents, and counsel work product.

## Release rules

1. Every public input is synthetic or an abstract schema.
2. Every empirical claim identifies its evidence class.
3. Private production evidence is not represented as independently reproducible from this package.
4. The public reference is never labeled as the production engine.
5. No repository visibility change may expose unrelated branches or history.
6. The Hugging Face Space must contain only the allowlisted `space/` files.
7. A pre-publication scan must check content, metadata, links, and generated artifacts.
8. Discovery of excluded content stops publication.
