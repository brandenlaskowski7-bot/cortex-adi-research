# Security and responsible disclosure

This release candidate contains a synthetic reference demonstrator, not a production service. Do not submit credentials, personal data, real floor plans, private merchandise feeds, customer records, or precise movement histories to the public demo.

If you find a vulnerability or believe excluded information is present:

1. stop interacting with the affected material;
2. preserve only the minimum evidence needed to describe the issue;
3. do not post credentials, personal data, private maps, or exploit details publicly; and
4. contact Cortex Agentics Global Inc. through an owner-approved private reporting channel.

No dedicated security mailbox is asserted in this release candidate. Until one is published by the owner, use the private contact method accompanying the review invitation.

Reports should include the release version, file or Space surface, reproduction steps, observed impact, and any suggested mitigation. Do not test against third-party systems or data without written authorization.
