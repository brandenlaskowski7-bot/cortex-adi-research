# Cortex Spatial Intelligence™ — Public Review Lab

This Space is an independently written, public-safe reference demonstrator for peer review of observable Cortex Spatial Intelligence concepts.

It allows reviewers to exercise wholly synthetic examples of:

- deterministic shopper and fulfillment-picker route planning;
- graph-distance stocking and replenishment sequencing;
- closest-first and farthest-first stocking modes;
- complete path reconstruction in the selected stocking order;
- governed weekly-sale and sponsored-promotion eligibility;
- deterministic promotion ranking and route-protection evidence; and
- repeated-input/repeated-output comparison by canonical SHA-256 digest.

## Disclosure boundary

This Space is **not** the private production SDK. It contains no production TypeScript source, proprietary adapter, customer map, real merchandise record, private positioning history, credential, infrastructure detail, or internal repository history.

The public reference implementation uses standard, independently written deterministic graph procedures solely to make the published contracts and review questions executable. A result here demonstrates only the public reference behavior under the included synthetic conditions.
