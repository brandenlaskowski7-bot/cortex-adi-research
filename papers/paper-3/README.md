# Deterministic Worker Construction Before Inference

**ADI Research Series Paper 3**  
Branden Laskowski · Cortex Agentics Global

Paper 3 is published as the archival preprint **Deterministic Worker Construction Before Inference**, version 0.9.

- [Zenodo record and DOI: 10.5281/zenodo.23603637](https://doi.org/10.5281/zenodo.23603637)
- Public release includes the manuscript and a public-safe evidence companion.

The paper distinguishes persistent, externally constructed worker state from temporary model inference. Its bounded empirical observations concern repeated input serialization under stated synthetic conditions; they do not establish universal quality preservation, general model equivalence, production savings, or disclosure of proprietary implementation. The archival record is the authoritative released artifact; this repository intentionally links to it rather than duplicating a different private draft.
