# Cortex ADI Research

**Probabilistic reasoning. Deterministic authority.**

The public research home for Cortex Agentics Global's Artificial Deterministic Intelligence (ADI) paper and planned weekly supporting series. Author: Branden Laskowski.

ADI proposes that probabilistic inference supplies bounded proposals while external systems govern identity, authority, memory admission, execution rights, state transitions, verification, and release. This is an architectural synthesis and research program with bounded first-party evidence. It is not a claim of deterministic language generation or a general safety guarantee.

ADI is the umbrella paper. One supporting paper is planned per week, subject to evidence and owner release review.
