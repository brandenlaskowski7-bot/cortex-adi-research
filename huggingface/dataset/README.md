# ADI Governed Memory Fixtures

Structured symbolic fixtures for testing ADI-inspired governed-memory decisions. The records are entirely synthetic and make a narrow set of outcomes inspectable: current eligibility, temporal expiry, supersession, conflict/HOLD, provenance requirements, scope and subject isolation, duplicate admission, replay, cleanup, and malformed input rejection.

## Included data

`fixtures.jsonl` contains declarative test scenarios. Each row identifies a synthetic scenario, its operations, and expected response characteristics. It contains no people, prompts, private documents, production records, credentials, or deployment details.

## What this dataset does not measure

It does not measure factual truth, general intelligence, model quality, real-world governance, or security. It is not a snapshot of Cortex or a production-memory system. A receipt is generated by a running synthetic lab and is intentionally not included in this fixture set.

## Use

Use the fixtures to test whether an implementation's observable decisions match the declared scenario outcomes. Report mismatches with the scenario identifier, expected and observed decision, reason category, receipt ID when present, and UTC time. Do not submit real data.
