Your synthetic experiment

A visit starts only when you run a scenario. Use End session when finished. If the frame is unavailable or cookies are blocked, open the lab in a new tab.

What happens when you leave?

Reset clears the experiment without extending your visit. End session revokes access and erases managed synthetic data. If you leave without ending, the server enforces the 15-minute idle or 90-minute absolute limit and retries cleanup until complete. Failed cleanup does not release the slot to another visitor.

This free Space serves the guide. The interactive client and isolated lab run on the owner’s existing Mac, so availability depends on that Mac, Docker, and its internet connection. Capacity is finite; a busy or offline response is not a successful test.

Help find a counterexample

Choose one invariant, run a synthetic scenario, and report the expected versus observed decision, reason category, receipt ID, and UTC time. Omit credentials and real data.

Report a synthetic failure ↗

Structured symbolic synthetic records only. No free-text or LLM inference. Not production Cortex. No independent security audit. Provenance presence is a source-reference check, not proof of truth. Managed-store deletion does not erase separate backups, provider metadata, screenshots, or offline copies.
